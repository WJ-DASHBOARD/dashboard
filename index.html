Perbarui data

Perubahan akan tersimpan online — siapa pun yang membuka link/file dashboard ini akan melihat data terbaru begitu mereka refresh atau membuka ulang.

1. Data Stok Outlet (CSV)

Update rutin. Kolom yang dipakai: brand, as_of_date, outlet_id, flag_position, flag, qty, amt.

2. Data Outlet / Pairing (Excel .xlsx)

Update bulanan. Sheet "IM3" dan "3ID"; outlet dengan PJP = "YES" atau Flag KAM = "KAM" yang dipakai. Kategori: KAM (Flag KAM) diprioritaskan, lalu KRO (Flag), sisanya PJP.

3. Data Sell In & GA — DSE_PROD (CSV, per brand)

Upload file IM3_DSE_PROD dan/atau 3ID_DSE_PROD bulan berjalan (region difilter otomatis ke WEST JAVA). Brand terdeteksi otomatis dari struktur kolom file. Bisa pilih 2 file (IM3 + 3ID) sekaligus — diproses satu per satu otomatis.

4. Data Supply — SUPPLY_PROD (CSV, per brand)

Upload file SUPPLY_PROD bulan berjalan (kolom brand, dt_id, sales_area, ret_qr_cd atau outlet_id, category, product_name, hit, rev — nama kolom Outlet ID boleh beda antara IM3/3ID). Brand dibaca langsung dari kolom "brand" di file. Bisa pilih 2 file (IM3 + 3ID) sekaligus.

5. Update Secondary (replace) — BigQuery export (CSV)

Ganti kolom Secondary di data Sell In & GA yang sudah ada, dari file transaksi mentah (kolom brand, region, outlet_id, parameter, rev, dst — 1 file berisi IM3+3ID sekaligus). Baris difilter otomatis ke region=WEST JAVA dan parameter=SECONDARY, lalu nilai rev dijumlahkan per outlet. Hanya kolom Secondary yang diganti — GA/Sell In SP/Voucher/Saldo/Tertiary tidak disentuh. Outlet yang tidak muncul di file ini akan di-set Secondary = 0 (dianggap tidak ada transaksi Secondary bulan tsb). Perlu data Sell In & GA (menu #3) sudah pernah diupload dulu.
