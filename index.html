Perbarui data

Perubahan akan tersimpan online — siapa pun yang membuka link/file dashboard ini akan melihat data terbaru begitu mereka refresh atau membuka ulang.

1. Data Stok Outlet (CSV)

Update rutin. Kolom yang dipakai: brand, as_of_date, outlet_id, flag_position, flag, qty, amt.

2. Data Outlet / Pairing (Excel .xlsx)

Update bulanan. Sheet "IM3" dan "3ID"; outlet dengan PJP = "YES" atau Flag KAM = "KAM" yang dipakai. Kategori: KAM (Flag KAM) diprioritaskan, lalu KRO (Flag), sisanya PJP.

3. Data Supply — SUPPLY_PROD (CSV, per brand)

Upload file SUPPLY_PROD bulan berjalan (kolom brand, dt_id, sales_area, ret_qr_cd atau outlet_id, category, product_name, hit, rev — nama kolom Outlet ID boleh beda antara IM3/3ID). Brand dibaca langsung dari kolom "brand" di file. Bisa pilih 2 file (IM3 + 3ID) sekaligus.

4. Update Secondary (replace) — BigQuery export (CSV)

Ganti kolom Secondary di data Sell In & GA yang sudah ada, dari file transaksi mentah (kolom brand, region, outlet_id, parameter, rev, dst — 1 file berisi IM3+3ID sekaligus). Baris difilter otomatis ke region=WEST JAVA dan parameter=SECONDARY, lalu nilai rev dijumlahkan per outlet. Hanya kolom Secondary yang diganti — GA/Sell In SP/Voucher/Saldo/Tertiary tidak disentuh. Outlet yang tidak muncul di file ini akan di-set Secondary = 0 (dianggap tidak ada transaksi Secondary bulan tsb). Perlu data Sell In & GA (menu #3) sudah pernah diupload dulu.

5. Update GA — file RGUGA atau file GA per MSISDN (CSV)

Ganti angka GA (MTD) di data Sell In & GA. Format file dikenali otomatis (bisa pilih beberapa file sekaligus):
• RGUGA harian — IM3_OUTLET_RGUGA_YYYYMM.csv / 3ID_OUTLET_RGUGA_YYYYMM.csv (⚠ angka RGUGA 3ID jauh lebih besar dari GA di DSE_PROD dan GA per MSISDN — untuk 3ID sebaiknya pakai export BigQuery atau file GA per MSISDN): kolom dt01…dt31 dijumlahkan dari tanggal 1 sampai tanggal terakhir yang ada datanya (kolom hari setelahnya yang nol semua diabaikan), semua baris & parameter per outlet dijumlah, hanya region WEST JAVA.
• Export BigQuery — file berkolom brand, dt_id, kpi, outlet_id, b_msisdn: hanya baris kpi = RET_TAG yang dihitung sebagai GA (huruf besar/kecil dan spasi tidak masalah; semua flag_outlet, termasuk 0). GA outlet = jumlah MSISDN unik per outlet_id di bulan terakhir pada file; IM3 & 3ID sekaligus, tanggal terakhir = dt_id terbaru per brand. File ini juga otomatis mengisi Sell In SP (Pcs) dari baris kpi = SELLIN yang ada di file yang sama — tidak perlu upload terpisah ke menu #9 lagi.
• GA per MSISDN — file berkolom msisdn, brand, ga_dt, tag_outlet: 1 baris = 1 aktivasi, GA outlet = jumlah baris (MSISDN unik) per tag_outlet di bulan terakhir pada file; IM3 & 3ID sekaligus dalam 1 file, tanggal terakhir = ga_dt terbaru per brand. Baris yang tag_outlet-nya kosong tidak bisa dihubungkan ke outlet, jadi tidak dihitung (jumlahnya ditampilkan setelah upload).
Outlet yang tidak muncul di file dianggap GA = 0. Hanya kolom GA yang diganti — Sell In, Tertiary, Secondary tidak disentuh. Berbeda dengan data Stock, yang memakai nilai as of tanggal terakhir (tidak dijumlah). Perlu data Sell In & GA (menu #3) sudah pernah diupload dulu. File 3ID besar (~150 MB), prosesnya bisa 1–2 menit.

6. Update Sell In (OSA) — file OSA_IM3 / OSA_3ID (CSV)

Ganti Sell In SP, Voucher, Saldo dari file OSA (kolom dt_id, qr_code/outlet_id, parameter, brand, amt — 1 baris per outlet per hari per parameter). Untuk tiap outlet, dipakai nilai di tanggal paling akhir yang ada di file (tidak dijumlah): osa_sp → Sell In SP, osa_vou → Sell In Voucher, osa_saldo → Sell In Saldo. Baris osa polos tidak dipakai. Bisa pilih 2 file (IM3 + 3ID) sekaligus. GA, Tertiary, dan Secondary tidak disentuh — cara kerjanya sama seperti upload DSE_PROD (menu #3), cuma sumber datanya beda.

7. Update Tertiary — file Tertiary (CSV)

Ganti kolom Tertiary dari file transaksi (kolom brand, dt_id, outlet_id, region_outlet, net_rev). Baris difilter ke region_outlet=WEST JAVA, lalu net_rev dijumlahkan per outlet (beda dengan OSA di atas yang pakai tanggal terakhir — Tertiary dijumlah). Hanya kolom Tertiary yang diganti — Sell In, GA, dan Secondary tidak disentuh. Perlu data Sell In sudah pernah diupload dulu.
